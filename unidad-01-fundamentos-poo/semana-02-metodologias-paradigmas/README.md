## Qué vas a aprender

- Qué es un paradigma y cómo se diferencian el procedural, el funcional y el orientado a objetos.
- Cómo resolver el mismo combate con funciones y con clases.
- Notación UML básica para modelar clases, atributos, métodos y relaciones.
- Fases del ciclo de desarrollo y prácticas de trabajo iterativas/ágiles.
- Cómo usar Git y GitHub como parte del proceso, no solo para entregar.
- Cómo se evalúa el curso con los proyectos P1, P2 y P3.


El script imprime la versión procedural, la versión orientada a objetos y una comparación final con el mismo estado.
