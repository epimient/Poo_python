# Semana 01 — Introducción al curso y a Python

Unidad 1 · Semana 01

## Qué vas a aprender

- Qué es la programación orientada a objetos y cómo se relacionan objeto y clase.
- Instalar y verificar Python 3.12 en Linux, Windows y macOS.
- Configurar Visual Studio Code, un entorno virtual (`venv`) y Git con GitHub.
- Escribir tu primera clase (`Personaje`) con atributos, constructor y métodos.
- Ejecutar scripts desde la terminal y entregar evidencias en el EVA/LMS.

## Cómo ejecutar

```bash
cd ejemplo-guiado
python3 personaje.py
```

Salida esperada: tres presentaciones, una tabla con el estado del equipo, una ronda de ataques y el estado final.

## Entregable de la semana

Un repositorio en GitHub llamado `poo-personajes` que contenga:

- `personaje.py` con la clase `Personaje` y el demo de tres personajes.
- `.gitignore` que excluya `.venv/` y `__pycache__/`.
- `README.md` con el comando de ejecución y una captura o bloque de la salida.
- Al menos dos commits: uno de configuración y uno con la clase funcionando.

Entrega el enlace del repositorio en el EVA/LMS antes del cierre de la semana.
