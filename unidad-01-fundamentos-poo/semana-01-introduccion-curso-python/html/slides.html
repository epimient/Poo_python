Concepto

Objeto y clase

Un objeto tiene estado (datos) y comportamiento (acciones). Una clase es el molde que describe cómo se crean esos objetos.

Una clase existe una vez en el código; los objetos pueden ser muchos y cada uno guarda sus propios valores.

Concepto

Todo en Python es un objeto

Ya has usado objetos sin llamarlos así. Un texto, un número y una lista son instancias de una clase.

>>> nombre = "Kaede"
>>> type(nombre)
<class 'str'>
>>> nombre.upper()
'KAEDE'
>>> type(42)
<class 'int'>

upper() es un método de la clase str. Cuando escribes nombre.upper() envías un mensaje al objeto, igual que harás con kaede.atacar(enemigo).

Reto: abre el intérprete y ejecuta type() sobre un entero, una lista, una tupla y una función. Todos son objetos.

Código · paso 1

Definir la clase

class Personaje:
    """Un personaje jugable con nombre, vida y ataque."""

    def __init__(self, nombre: str, hp: int, ataque: int) -> None:
        self.nombre = nombre
        self.hp = hp
        self.ataque = ataque
  • class crea el molde.
  • __init__ se ejecuta al crear el objeto.
  • self es la referencia al objeto que se construye.
  • Cada atributo vive en el objeto, no en la clase.

Declara todos los atributos en __init__. Un atributo creado después puede no existir cuando lo necesites.

Código · paso 2

Agregar comportamiento

    def presentarse(self) -> str:
        return f"Soy {self.nombre} y tengo {self.hp} HP."

    def atacar(self, objetivo: "Personaje") -> None:
        dano = self.ataque
        objetivo.hp = max(0, objetivo.hp - dano)
        print(f"{self.nombre} ataca a {objetivo.nombre}.")
        print(f"{objetivo.nombre} queda con {objetivo.hp} HP.")

    def esta_vivo(self) -> bool:
        return self.hp > 0

atacar recibe otro objeto y modifica su estado. max(0, ...) evita vidas negativas: una regla pequeña del dominio.

Código · paso 3

Crear tres personajes

kaede = Personaje("Kaede", 120, 18)
rook = Personaje("Rook", 90, 24)
nima = Personaje("Nima", 100, 14)
equipo = [kaede, rook, nima]

for personaje in equipo:
    print(personaje.presentarse())

kaede.atacar(rook)
rook.atacar(kaede)
nima.atacar(rook)

Cada llamada a Personaje(...) crea una instancia independiente. kaede.hp y rook.hp son atributos distintos aunque compartan el nombre en el código.
