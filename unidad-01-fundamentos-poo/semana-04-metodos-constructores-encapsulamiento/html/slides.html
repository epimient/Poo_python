Métodos, constructores y encapsulamiento

Que tus objetos sepan defenderse de los datos inválidos

POO con Python

Objetivos

Al terminar podrás…

  • Escribir métodos de instancia que modifican el estado.
  • Usar valores por defecto y fábricas con @classmethod.
  • Aplicar @staticmethod y distinguirlo de los otros métodos.
  • Proteger atributos con _, __ y @property.
  • Validar con setters y lanzar ValueError.
  • Definir __str__ y __repr__.

El problema

Datos sin reglas, bugs garantizados

aria = Personaje("Aria", hp=10)
aria.recibir_danio(50)

print(aria.hp)   # -40  ← estado imposible

cuenta = CuentaBancaria("Ada", 100)
cuenta.saldo = -1_000_000   # nadie lo impide
El error no aparece donde se escribe el dato, sino mucho después y en otro lugar. El encapsulamiento lo detiene en la puerta.

Encapsular no es esconder por moda: es garantizar que el objeto cumpla sus reglas.

Código 1

Métodos de instancia

class Personaje:
    def __init__(self, nombre: str, hp: int = 100) -> None:
        self.nombre = nombre
        self.hp = hp

    def saludar(self) -> str:
        return f"Soy {self.nombre} y tengo {self.hp} hp."

    def recibir_danio(self, cantidad: int) -> int:
        self.hp = max(0, self.hp - cantidad)
        return cantidad

aria = Personaje("Aria", 80)
print(aria.saludar())

self se enlaza solo: aria.saludar() equivale a Personaje.saludar(aria).

Código 2

Constructores con valores por defecto

class Personaje:
    MAX_HP = 100

    def __init__(self, nombre: str, hp: int = MAX_HP,
                 ataque: int = 10) -> None:
        self.nombre = nombre
        self.hp = hp
        self.ataque = ataque

brom = Personaje("Brom")           # 100 hp, ataque 10
aria = Personaje("Aria", 80, 18)   # 80 hp, ataque 18
Nunca uses [] o {} como valor por defecto: se comparten entre todas las instancias. Usa None y crea el mutable dentro.

Código 3

@classmethod: una fábrica

class Personaje:
    def __init__(self, nombre: str, hp: int, ataque: int) -> None:
        self.nombre = nombre
        self.hp = hp
        self.ataque = ataque

    @classmethod
    def desde_ficha(cls, ficha: str) -> "Personaje":
        nombre, hp, ataque = (p.strip() for p in ficha.split(","))
        return cls(nombre, int(hp), int(ataque))

brom = Personaje.desde_ficha("Brom, 120, 15")

Recibe cls y construye con cls(...). Si mañana existe una subclase, la fábrica devolverá el tipo correcto.

Código 4

@staticmethod: utilidad sin estado

class Personaje:
    @staticmethod
    def calcular_danio(ataque: int, defensa: int) -> int:
        return max(1, ataque - defensa)

print(Personaje.calcular_danio(18, 4))  # 14

# También se puede llamar desde una instancia
aria = Personaje()
print(aria.calcular_danio(10, 2))       # 8

Encapsulamiento

Protegido, privado y name mangling

class CuentaBancaria:
    def __init__(self, titular: str, saldo: float) -> None:
        self.titular = titular      # público
        self._saldo = saldo         # protegido
        self.__clave = "0000"       # name mangling

cuenta = CuentaBancaria("Ada", 250.0)

print(cuenta._saldo)                 # 250.0 (no deberías)
print(cuenta._CuentaBancaria__clave) # "0000"
# print(cuenta.__clave)              # AttributeError
El guion bajo es una convención, no un candado. La protección real aparece cuando no hay ninguna vía pública para romper el estado.

Código 5

@property y setter validado

class Personaje:
    def __init__(self, nombre: str, hp_max: int = 100) -> None:
        self.nombre = nombre
        self.hp_max = hp_max
        self._hp = hp_max

    @property
    def hp(self) -> int:
        return self._hp

    @hp.setter
    def hp(self, valor: int) -> None:
        if not 0 <= valor <= self.hp_max:
            raise ValueError(f"hp fuera de rango: {valor}")
        self._hp = valor

aria.hp = 500   # ValueError
aria.hp = -1    # ValueError
Dentro del setter usa self._hp = valor. Con self.hp = valor el setter se llama a sí mismo y termina en RecursionError.

Ejemplo 1

Combate con estado consistente

class Personaje:
    def atacar(self, objetivo: "Personaje") -> int:
        if not self.vivo:
            raise ValueError(f"{self.nombre} está derrotado.")
        danio = self.calcular_danio(self.ataque, objetivo.defensa)
        return objetivo.recibir_danio(danio)

    def recibir_danio(self, cantidad: int) -> int:
        antes = self._hp
        self.hp = max(0, self._hp - cantidad)
        return antes - self._hp

    def curar(self, cantidad: int) -> int:
        antes = self._hp
        self.hp = min(self.hp_max, self._hp + cantidad)
        return self._hp - antes

recibir_danio y curar devuelven el cambio real, no lo que se pidió.

Ejemplo 2

Cuenta con saldo protegido

class CuentaBancaria:
    @property
    def saldo(self) -> float:
        return self._saldo

    def depositar(self, monto: float) -> float:
        monto = self._validar_monto(monto)
        self._saldo = round(self._saldo + monto, 2)
        self._registrar("Depósito", monto)
        return monto

    def retirar(self, monto: float) -> float:
        monto = self._validar_monto(monto)
        if monto > self._saldo:
            raise ValueError("Saldo insuficiente.")
        self._saldo = round(self._saldo - monto, 2)
        self._registrar("Retiro", -monto)
        return monto

El saldo solo cambia por operaciones válidas. El historial se entrega como tupla para que nadie lo edite.

Representación

__str__ vs. __repr__

def __str__(self) -> str:
    return f"{self.nombre} ({self._hp}/{self.hp_max} hp)"

def __repr__(self) -> str:
    return (f"Personaje(nombre={self.nombre!r}, hp={self._hp}, "
            f"hp_max={self.hp_max})")

print(aria)        # Aria (6/90 hp)
print(repr(aria))  # Personaje(nombre='Aria', hp=6, hp_max=90)

Errores comunes

Donde se rompe el encapsulamiento

  • Recursión: self.hp = valor dentro del setter hp.
  • Validar después de asignar: el objeto ya quedó inválido.
  • Lista o diccionario como valor por defecto del constructor.
  • Devolver un valor desde un setter: se ignora.
  • Creer que __saldo es privado de verdad: se accede con _Clase__saldo.
  • __str__ que devuelve algo distinto de str.
Un try/except ValueError: pass esconde el error y deja el estado a medias. Captura para informar, no para silenciar.

Reto

Cuenta bancaria con reglas

Amplía la clase CuentaBancaria con estas reglas:

  • El saldo inicial no puede ser negativo.
  • Depósitos y retiros deben ser mayores que cero.
  • No se puede retirar más de lo disponible.
  • Guarda cada movimiento en una lista interna y expón una copia de solo lectura.
  • Añade __str__ y __repr__, y demuestra al menos tres errores capturados.
Reto extra: permite un descubierto de hasta $200 con una propiedad disponible, sin romper la regla del saldo.

Resumen

Lo que te llevas

  • Los métodos convierten el estado en comportamiento.
  • El constructor acepta valores por defecto, nunca mutables compartidos.
  • @classmethod fabrica objetos; @staticmethod calcula sin estado.
  • _ y __ son convenciones; @property es la puerta validada.
  • ValueError protege las reglas del dominio.
  • __str__ habla con el usuario; __repr__ con quien depura.
