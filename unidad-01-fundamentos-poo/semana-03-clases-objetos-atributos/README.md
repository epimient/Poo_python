# Semana 03 — Clases, objetos y atributos

Unidad 1 · Semana 03

## Qué vas a aprender

A definir tus propias clases con `class`, inicializarlas con `__init__`, guardar datos por objeto con `self` y distinguir atributos de instancia de atributos de clase. También verás cómo comprobar identidad y tipo, inspeccionar `__dict__` y evitar el error clásico de compartir una lista entre todas las instancias.

## Cómo ejecutar

```bash
cd ejemplo-guiado
python3 personaje.py
```

No necesitas instalar nada: solo Python 3.12 o superior y una terminal.

## Entregable de la semana

Un script `personaje.py` que defina la clase `Personaje` con atributos de instancia (`nombre`, `hp`, `nivel`) y de clase (`MAX_HP` y un contador de personajes creados), construya un equipo de al menos tres personajes y muestre su estado, el total de personajes y el contenido de `__dict__` de cada uno.
