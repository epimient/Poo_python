Concepto

Una clase es un plano; un objeto es una casa

El plano define cuántas habitaciones hay. Cada casa tiene su dirección, sus muebles y su estado. Cambiar una casa no cambia las demás.

class Personaje Personaje("Aria") Personaje("Brom") Personaje("Cyd") 
class Personaje:
    pass

aria = Personaje()
brom = Personaje()

print(aria is brom)                 # False
print(type(aria).__name__)          # Personaje
print(isinstance(aria, Personaje))  # True

is compara identidad, no contenido. Dos objetos con los mismos datos siguen siendo distintos.

Código 1

__init__ y self

class Personaje:
    def __init__(self, nombre: str, hp: int = 100, nivel: int = 1) -> None:
        self.nombre = nombre
        self.hp = hp
        self.nivel = nivel

aria = Personaje("Aria", 80, 3)
brom = Personaje("Brom")

print(aria.hp)   # 80
print(brom.hp)   # 100
  • __init__ se ejecuta al crear el objeto.
  • self es el objeto que se está inicializando.
  • Python pasa self solo: no lo escribas al llamar.
__init__ debe devolver None. Un return con valor lanza TypeError.

Código 2

Instancia vs. clase

class Personaje:
    MAX_HP = 100           # atributo de clase
    total_personajes = 0   # contador compartido

    def __init__(self, nombre: str, hp: int = MAX_HP) -> None:
        self.nombre = nombre   # atributo de instancia
        self.hp = hp
        Personaje.total_personajes += 1

Código 3

Un contador que sí es global

aria = Personaje("Aria", 80, 3)
brom = Personaje("Brom")
cyd = Personaje("Cyd", 45, 5)

print(Personaje.total_personajes)  # 3
print(Personaje.MAX_HP)            # 100
print(aria.MAX_HP)                 # 100 (se lee de la clase)

# MAL: crea un atributo de instancia y tapa el global
# self.total_personajes += 1

# BIEN: actualiza el contador compartido
Personaje.total_personajes += 1
Los atributos de clase se leen desde la instancia, pero se modifican a través de la clase.

Código 4

__dict__: lo que realmente tiene cada objeto

print(aria.__dict__)
# {'nombre': 'Aria', 'hp': 80, 'nivel': 3}

print('MAX_HP' in aria.__dict__)  # False
print(Personaje.__dict__['MAX_HP'])  # 100

cyd.MAX_HP = 120          # crea un atributo propio
print(cyd.MAX_HP)         # 120
print(Personaje.MAX_HP)   # 100: la clase no cambió

__dict__ muestra solo el estado propio. Los atributos de clase se buscan en la clase cuando no están en la instancia.

Error clásico

La lista compartida

class Gremio:
    miembros = []   # ¡una sola lista para todos!

alba = Gremio()
sombra = Gremio()

alba.miembros.append("Aria")
print(sombra.miembros)   # ['Aria']  ← desastre
class Gremio:
    def __init__(self, nombre: str) -> None:
        self.nombre = nombre
        self.miembros: list[str] = []   # lista propia
Listas, diccionarios y conjuntos se crean dentro de __init__. Nunca como atributo de clase.

Errores comunes

Los tropiezos de la semana

  • Olvidar self en la definición del método.
  • Escribir Personaje cuando querías Personaje().
  • Inicializar una lista como atributo de clase.
  • Incrementar el contador con self.total_personajes.
  • Suponer que __dict__ incluye los atributos de clase.
Antes de crear un atributo, pregúntate: ¿este dato es igual para todos o cambia por objeto?

Resumen

Lo que te llevas

  • La clase define el tipo; cada objeto guarda su propio estado.
  • __init__ recibe self y asigna atributos de instancia.
  • Los atributos de clase son constantes y contadores compartidos.
  • type(), isinstance(), is e id() revelan qué es cada objeto.
  • __dict__ enseña el estado real de una instancia.
