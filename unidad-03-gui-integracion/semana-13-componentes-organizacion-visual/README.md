# Semana 13 — Componentes y organización visual

Unidad 3 · Semana 13

## Qué vas a aprender

- Usar widgets `ttk`: `Label`, `Entry`, `Combobox`, `Treeview`, `Notebook` y `Button`.
- Agrupar controles con `Frame` y `LabelFrame`.
- Definir estilos coherentes con `ttk.Style`.
- Construir formularios con variables, validación visual y feedback.
- Aplicar jerarquía visual, espaciado y alineación.
- Prototipar un creador de personajes completo.

## Cómo ejecutar

```bash
cd ejemplo-guiado
python3 creador_personaje.py
```

También puedes probar el cajero:

```bash
python3 cajero_basico.py
```

Ambos abren una ventana real y se cierran con la **X**, con **Alt+F4** o con **Ctrl+C** en la terminal.

## Entregable de la semana

Un creador de personajes con formulario `ttk`, validación visual, vista previa y lista de personajes. El modelo debe validar por su cuenta y la vista debe limitarse a mostrar el resultado o el error. Código ejecutable con `python3 archivo.py`, sin dependencias externas.
