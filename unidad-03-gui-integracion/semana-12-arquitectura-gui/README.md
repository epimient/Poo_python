# Semana 12 — Arquitectura de GUI

Unidad 3 · Semana 12

## Qué vas a aprender

- Qué es una interfaz gráfica y cómo funciona el bucle de eventos.
- Crear una ventana raíz con `tk.Tk()` y cerrarla correctamente.
- Usar `Label`, `Button`, `Entry` y `Frame`.
- Colocar widgets con `pack`, `grid` y `place`, y saber cuándo usar cada uno.
- Organizar los widgets en una jerarquía de contenedores.
- Separar la lógica del videojuego de la interfaz y aplicar MVC.

## Cómo ejecutar

```bash
cd ejemplo-guiado
python3 hola_tkinter.py
```

También puedes abrir la ficha de personaje:

```bash
python3 ficha_personaje.py
```

Cada comando abre una ventana real. Se cierra con la **X** de la barra de título, con **Alt+F4** o con **Ctrl+C** en la terminal.

## Entregable de la semana

Un programa Tkinter con una ventana de estadísticas de tu equipo, el modelo separado de la vista y un wireframe (papel o imagen) de la pantalla. El código debe ejecutarse con `python3 archivo.py` sin dependencias externas.
