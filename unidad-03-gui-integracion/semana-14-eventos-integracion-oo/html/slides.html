Concepto

El objeto evento

Tkinter lo crea y lo pasa a tu función cuando usas bind.

def _al_pulsar_tecla(self, evento: tk.Event) -> None:
    print(evento.keysym)   # "a", "Return", "Escape"
    print(evento.x)        # posición del ratón
    print(evento.widget)   # widget que recibió el evento

    if (evento.keysym or "").lower() == "a":
        self._atacar()
  • keysym: nombre de la tecla.
  • char: carácter escrito, si existe.
  • num: botón del ratón que se pulsó.

Modelo

Ciclo evento → lógica → vista

clic / tecla / after callback método del dominio estado + eventos _refrescar() etiquetas y barras

La flecha nunca va del dominio a la vista. Combate no sabe que existe un Label.

def _atacar(self):
    eventos = self.combate.turno_jugador()  # lógica
    self._escribir(eventos)                 # vista
    self._refrescar()                       # vista

Código · dominio

Un personaje que no conoce Tkinter

class Personaje:
    def __init__(self, nombre, clase, hp_max, ataque, defensa):
        if hp_max <= 0 or ataque <= 0 or defensa < 0:
            raise ValueError("Estadísticas inválidas")
        self.nombre = nombre
        self.hp_max = hp_max
        self.hp = hp_max
        self.ataque = ataque
        self.defensa = defensa

    @property
    def esta_vivo(self) -> bool:
        return self.hp > 0

    def recibir_dano(self, cantidad: int) -> int:
        aplicado = min(max(0, cantidad), self.hp)
        self.hp -= aplicado
        return aplicado

Se puede probar en el intérprete, sin abrir una ventana.

El combate decide

def turno_jugador(self) -> list[tuple[str, str]]:
    if self.terminado:
        return [("sistema", "El combate ya terminó.")]

    dano = self.jugador.atacar(self.enemigo, self.rng)
    eventos = [("jugador", f"Atacas y quitas {dano} de HP.")]

    if not self.enemigo.esta_vivo:
        self.terminado = True
        self.ganador = self.jugador.nombre
        eventos.append(("sistema", "¡Victoria!"))

    self.log.extend(eventos)
    return eventos

def _atacar(self) -> None:
    if self.combate is None or self.combate.terminado:
        return

    self._escribir(eventos)

def _al_pulsar_tecla(self, evento: tk.Event) -> None:
    foco = self.ventana.focus_get()
    if isinstance(foco, (tk.Entry, ttk.Entry, ttk.Combobox)):
        return  # no atacar mientras se escribe
    if (evento.keysym or "").lower() == "a":
        self._atacar()

Código · persistencia

Guardar sin guardar objetos

def a_dict(self) -> dict[str, object]:
    return {
        "turno": self.turno,
        "terminado": self.terminado,
        "ganador": self.ganador,
        "jugador": self.jugador.a_dict(),
        "enemigo": self.enemigo.a_dict(),
        "log": [{"tipo": t, "texto": x} for t, x in self.log],
    }

def guardar_partida(combate, ruta=RUTA_PARTIDA):
    texto = json.dumps(combate.a_dict(), ensure_ascii=False, indent=2)
    temporal = ruta.with_name(ruta.name + ".tmp")
    temporal.write_text(texto + "\n", encoding="utf-8")
    temporal.replace(ruta)
    return ruta

Escribir en un temporal y reemplazar evita dejar la partida a medias si el programa se cierra.

Errores comunes

Lo que rompe la integración

  • Paréntesis de más: command=self._atacar().
  • Dormir el bucle: time.sleep() congela la ventana; usa after.
  • Duplicar lógica: una copia en el botón y otra en la tecla.
  • Serializar objetos: json.dumps(personaje) lanza TypeError.
  • Confiar en el archivo: un JSON incompleto debe dar un error claro.
  • Atacar dos veces: deshabilita el botón mientras responde el enemigo.

El dominio no debe importar tkinter ni crear widgets.

Resumen

Lo que te llevas

  • Los eventos son la entrada, no el cerebro de la aplicación.
  • command para la acción principal; bind para gestos extra.
  • Un callback delgado valida, delega y refresca.
  • Dominio, persistencia y vista se comunican en una sola dirección.
  • JSON explícito, validado y guardado de forma atómica.
