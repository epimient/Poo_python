# Semana 16 — Retroalimentación y cierre

Unidad 3 · Semana 16

## Qué vas a aprender

- Revisar el código de un compañero con una checklist de calidad y comentarios accionables.
- Sustentar tu proyecto en ocho minutos explicando decisiones, no líneas de código.
- Publicar un portafolio en GitHub con README, demo e historial de commits.
- Autoevaluarte con la rúbrica del curso y definir tu siguiente paso de estudio.

## Cómo ejecutar

```bash
cd ejemplo-guiado
python3 revision_final.py
```

El ejemplo no pide datos: analiza dos fragmentos incluidos en el propio archivo y muestra el informe en la consola.

## Entregable de la semana

Tres evidencias breves en tu repositorio:

1. La revisión que hiciste al proyecto de un compañero (cinco comentarios accionables).
2. La revisión que recibiste y qué cambiaste a partir de ella.
3. Una sección «Próximos pasos» en tu README con tres tareas concretas para las siguientes dos semanas.
